
```tsx tab="Link"
<Button variant="link" href="/issues">Read the archive</Button>
```

<Callout title="href changes the element">
  Pass `href` and you get an `<a>`; leave it off and you get a `<button>`. The `variant="link"`
  styling is independent of which element renders.
</Callout>

## Pending state

`pending` is the whole reason this component exists rather than a styled `<button>`. It
keeps the width stable so the layout does not jump when the label is replaced.

```tsx lineNumbers
'use client';

import { Button } from '@letterstack/react';
import { useState } from 'react';

export function SubscribeButton() {
  const [pending, setPending] = useState(false);

  return (
    <Button
      pending={pending} // [!code highlight]
      onClick={async () => {
        setPending(true);
        try {
          await subscribe();
        } finally {
          setPending(false);
        }
      }}
    >
      Subscribe
    </Button>
  );
}
```

## Composing with asChild

Use `asChild` when something else owns the element — a framework `Link`, for instance.

```tsx
import Link from 'next/link';

<Button asChild variant="link">
  <Link href="/issues">Read the archive</Link>
</Button>
```

<Callout type="error" title="asChild needs exactly one child">
  Two children, or a text node, will throw. The component has one element to merge into and
  no way to choose.
</Callout>

## Accessibility

- `pending` sets `aria-busy="true"` and leaves the accessible name alone.
- `disabled` uses `aria-disabled`, so the button keeps focus and any tooltip stays reachable.
- The rendered element is a real `button` or `a`. No `div` with a click handler.

```txt title="Keyboard"
Tab          move focus to the button
Enter        activate (button and anchor)
Space        activate (button only)
```
