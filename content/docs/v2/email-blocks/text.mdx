## Examples

### Links and emphasis

Children can hold inline elements. Style links yourself: email clients don't share one default
link style.

<EmailPreview height={150}>
  <Text>
    Read <strong>the full story</strong> on{' '}
    <a href="https://example.com" style={{ color: '#E05C3A' }}>our blog</a>.
  </Text>
</EmailPreview>

```tsx
<Text>
  Read <strong>the full story</strong> on{' '}
  <a href="https://example.com" style={{ color: '#E05C3A' }}>our blog</a>.
</Text>
```
