<Callout type="warn" title="Colour is not a label">
  A red badge that says "Live" and a green badge that says "Live" mean the same thing to a
  screen reader. If the tone carries information, put it in the text too.
</Callout>

## In a list

Badges are inline elements, so they sit inside text without breaking the line box.

```tsx
<PostCard
  title="Issue 41"
  badge={<Badge tone="accent">Members only</Badge>}
/>
```

## Data attributes

| Attribute | Values |
| --- | --- |
| `data-ls-badge` | present on the root |
