## Lay out an issue [step]

`Prose` sets the measure, vertical rhythm, and heading scale. `Byline` and `Estimate` read
from the same post object so they cannot drift apart.

```tsx title="app/issues/[slug]/page.tsx" lineNumbers
import { Byline, Estimate, Prose, ReadingProgress } from '@letterstack/react';
import { getIssue } from '@/lib/issues';

export default async function IssuePage({ params }: { params: Promise<{ slug: string }> }) {
  const issue = await getIssue((await params).slug);

  return (
    <>
      <ReadingProgress /> {/* [!code highlight] */}
      <Prose measure="comfortable">
        <h1>{issue.title}</h1>
        <Byline author={issue.author} publishedAt={issue.publishedAt} />
        <Estimate words={issue.wordCount} />
        {issue.body}
      </Prose>
    </>
  );
}
```

<Callout title="Why measure and not max-width?">
  `measure` is expressed in characters per line, not pixels, so it holds up when the reader
  bumps the base font size. `comfortable` is 66ch; `tight` is 52ch; `wide` is 80ch.
</Callout>

## Add the subscribe form [step]

The form is uncontrolled and posts to whatever `action` you give it. Validation, the
pending state, and the error region are handled for you.

```tsx title="app/issues/page.tsx"
import { SubscribeForm } from '@letterstack/react';

<SubscribeForm action="/api/subscribe" placeholder="you@example.com">
  <SubscribeForm.Label>Get every issue in your inbox</SubscribeForm.Label>
  <SubscribeForm.Input />
  <SubscribeForm.Submit>Subscribe</SubscribeForm.Submit>
  <SubscribeForm.Error />
</SubscribeForm>
```

## List the archive [step]

`Archive` virtualises its list, so the markup cost is the same at fifty issues and at five
thousand.

```tsx title="app/issues/page.tsx"
import { Archive, PostCard } from '@letterstack/react';

<Archive items={issues} groupBy="year">
  {(issue) => (
    <PostCard
      key={issue.slug}
      href={`/issues/${issue.slug}`}
      title={issue.title}
      excerpt={issue.excerpt}
      date={issue.publishedAt}
    />
  )}
</Archive>
```
