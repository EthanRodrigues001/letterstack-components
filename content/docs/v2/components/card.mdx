```tsx
import { Card } from '@letterstack/react';

<Card>
  <Card.Header>
    <Card.Title>Issue 41</Card.Title>
    <Card.Description>Every other Thursday</Card.Description>
  </Card.Header>
  <Card.Body>Six months of reader mail, sorted.</Card.Body>
  <Card.Footer>
    <Button variant="link" href="/issues/41">Read</Button>
  </Card.Footer>
</Card>
```

## Slots

Each slot is optional and renders nothing when absent — no empty padding left behind.

## Clickable cards

A card-wide link wrapping other links produces nested interactive elements, which is
invalid and behaves unpredictably. `href` on `Card` uses an overlay anchor instead, so
links inside the card still work.

```tsx
<Card href="/issues/41" interactive>
  <Card.Title>Issue 41</Card.Title>
  <Card.Body>
    Featuring <a href="/authors/ada">Ada</a> {/* [!code highlight] */}
  </Card.Body>
</Card>
```

<Callout title="Why an overlay?">
  The overlay anchor sits above the card but below any other interactive element, so the
  inner link wins the click and the rest of the card still navigates.
</Callout>

## With media

```tsx
<Card orientation="horizontal">
  <Card.Media>
    <img src="/covers/41.webp" alt="" />
  </Card.Media>
  <Card.Header>
    <Card.Title>Issue 41</Card.Title>
  </Card.Header>
</Card>
```

<Callout type="idea" title="Decorative images">
  `alt=""` is correct when the title already describes the card. An empty alt removes the
  image from the accessibility tree; a missing alt makes the screen reader read the filename.
</Callout>
