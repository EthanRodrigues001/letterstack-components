## Conventions shared by every component

<Steps>
  <Step>
    ### className is forwarded
    Always to the outermost element, always last in the class list.
  </Step>
  <Step>
    ### asChild renders into your element
    Pass `asChild` and a single child, and the component merges its props into that child
    instead of wrapping it.
  </Step>
  <Step>
    ### Data attributes are public
    `[data-ls-button]`, `[data-state]`, `[data-variant]`. Class names are not.
  </Step>
  <Step>
    ### Server-first
    Nothing has `'use client'` unless it genuinely needs an event handler.
  </Step>
</Steps>
