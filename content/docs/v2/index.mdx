LetterStack is a set of React components for people who publish words. It gives you the
primitives behind a newsletter or editorial site — layout, typography, subscribe forms,
archives, reading progress — without deciding how any of it should look.

## Why another component library?

Most component libraries are built for dashboards. Tables, charts, date pickers, command
palettes. Publishing has a different set of problems: long-form measure, footnotes that
stay attached to their paragraph, an archive that stays fast at ten thousand posts, and a
subscribe form that survives being embedded in someone else's page.

LetterStack ships those pieces instead.
