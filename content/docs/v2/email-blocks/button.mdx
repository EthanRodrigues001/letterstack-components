## Usage

```tsx
import { Button } from '@/components/email/button';

<Button href="https://example.com">Read the full newsletter</Button>
```

Buttons are plain `<a>` tags with inline styles, not `<button>` elements. Email clients strip
forms and scripts, so a link is the only kind of button that works in an inbox.

### Two buttons side by side

`<Button>` takes a whole row. To put two actions next to each other, use `<ButtonGroup>` with a
`<ButtonLink>` for each one.

<EmailPreview height={140}>
  <ButtonGroup align="center">
    <ButtonLink href="#">Upgrade</ButtonLink>
    <ButtonLink href="#" variant="secondary">Maybe later</ButtonLink>
  </ButtonGroup>
</EmailPreview>

```tsx
<ButtonGroup align="center">
  <ButtonLink href="#">Upgrade</ButtonLink>
  <ButtonLink href="#" variant="secondary">Maybe later</ButtonLink>
</ButtonGroup>
```

  type={{

`<ButtonLink>` takes `href`, `variant`, `fullWidth` and `theme`. `<ButtonGroup>` takes `align`,
`theme` and the row props.
